## Goal

Diagnose and fix Vivado hardware connection failures on Linux. Root cause is almost
always missing udev/cable drivers for the Digilent JTAG USB cable (FTDI FT2232).

---

## Step 1 — Confirm board is detected by OS

```bash
lsusb | grep -iE "digilent|ftdi"
```

**Expected** (board detected, drivers missing):
```
Bus 003 Device 004: ID 0403:6010 Future Technology Devices International, Ltd FT2232C/D/H Dual UART/FIFO IC
```

**Nothing returned?** Board not seen by OS at all. Check:
- Cable is data-capable micro USB (not charge-only)
- Board power switch is ON
- Correct USB port: PROG/JTAG port (on Basys 3: left side when facing board, labeled "PROG")
- Try a different USB port on the host

If board still absent after checks, run full `lsusb` to confirm USB subsystem is working.

---

## Step 2 — Find Vivado install path

```bash
which vivado 2>/dev/null || find /opt /tools -maxdepth 6 -name "vivado" -type f 2>/dev/null | head -3
```

Vivado is typically at `/tools/Xilinx/<year>/Vivado/` or `/opt/Xilinx/Vivado/<year>/`.

---

## Step 3 — Install cable drivers

Replace `<VIVADO_ROOT>` with the path from Step 2 (e.g., `/tools/Xilinx/2025.2/Vivado`):

```bash
sudo <VIVADO_ROOT>/data/xicom/cable_drivers/lin64/install_script/install_drivers/install_drivers && sudo udevadm control --reload-rules && sudo udevadm trigger
```

This installs udev rules for Digilent and FTDI devices and reloads them immediately.

---

## Step 4 — Reconnect and test

1. Physically unplug and replug the USB cable
2. In Vivado: **Flow Navigator → Open Hardware Manager → Open Target → Auto Connect**

If Auto Connect succeeds, the board appears in the Hardware panel. Proceed to program.

---

## Common follow-up issues

| Symptom | Fix |
|---|---|
| `ERROR: [Labtoolstcl 44-26] No hardware targets exist` after driver install | Unplug/replug USB, try Auto Connect again |
| Driver install fails with permission error | Ensure `sudo` is available; some corp Linux setups restrict it |
| Board detected by lsusb but Vivado still fails | Add user to `dialout` group: `sudo usermod -aG dialout $USER` then log out/in |
| Multiple boards connected | Specify target explicitly in Vivado TCL: `open_hw_target [lindex [get_hw_targets] 0]` |

---

## Reference: Basys 3 (XC7A35T) quick facts

- JTAG chip: FTDI FT2232 (USB ID `0403:6010`)
- Clock pin: W5
- IOSTANDARD for all I/O: LVCMOS33
- Programming file: `.bit` (generated by `write_bitstream`)
